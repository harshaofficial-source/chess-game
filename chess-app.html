About this app

Everything here — the AI, puzzles, and lessons — runs entirely in your browser, so it all works offline once the page is loaded. Real-time online multiplayer would need a live backend server to relay moves between devices, which a page like this can't host on its own. The "Play by Code" mode is an asynchronous workaround: it lets two people share a game by exchanging short text codes.
